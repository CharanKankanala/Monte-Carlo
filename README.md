# Multi-Asset Fintech Risk Lab

An end-to-end quantitative research platform for testing implementable portfolio strategies against transparent benchmarks. It combines real multi-asset market data, walk-forward backtesting, trading frictions, conditional-volatility and regime models, heavy-tail simulation, statistical validation, automated refreshes, and an interactive research dashboard.

## What makes this different

- **Real market data:** adjusted prices for nine liquid asset-class ETFs from 2014 onward
- **Strict out-of-sample design:** 504-day trailing estimation windows and 21-day rebalancing
- **Four allocation policies:** equal weight, minimum variance, momentum tilt, and risk parity
- **Honest benchmarks:** S&P 500 and 60/40 equity–Treasury portfolios remain visible
- **Implementation realism:** turnover-based costs and an additional liquidity-stress scenario
- **Advanced risk models:** GARCH(1,1), a two-state hidden Markov regime model, and a heavy-tail rank copula
- **Competing simulations:** moving-block bootstrap versus GARCH–regime–t-copula Monte Carlo
- **Formal diagnostics:** normality/dependence checks, benchmark tests, and Kupiec VaR coverage
- **Interactive product:** responsive dashboard with strategy, model, and cost-stress controls
- **Research operations:** automated tests, CI builds, cached data provenance, and weekly refresh workflow

## Latest validated finding

The current real-data run covers 3,154 aligned trading days from January 2014 through July 2026. The S&P 500 led raw CAGR, the 60/40 benchmark led realized risk-adjusted performance, and minimum variance produced the shallowest maximum drawdown. The advanced heavy-tail model estimated more severe 95% tail loss than the historical bootstrap. These results demonstrate benchmark honesty rather than forcing a complex strategy to appear superior.

## Quick start

```bash
python -m pip install -r requirements.txt
python research_pipeline.py --refresh --paths 10000
python -m pytest -q
```

The cached production dataset allows offline reproduction. `--refresh` retrieves the latest adjusted prices when network access is available.

To run the interactive dashboard:

```bash
cd dashboard
pnpm install
pnpm dev
```

## Research outputs

The pipeline exports walk-forward returns and wealth, allocation history, turnover and costs, benchmark tests, statistical diagnostics, GARCH parameters, regime probabilities, VaR coverage, competing model metrics, and a generated research report. The dashboard consumes a compact, versioned `results.json` payload generated by the same pipeline.

See [RESEARCH_METHODOLOGY.md](RESEARCH_METHODOLOGY.md) for the complete experimental protocol and [RESEARCH_REPORT.md](RESEARCH_REPORT.md) for current findings.

## Architecture

```text
portfolio_risk/
  core.py              bootstrap simulation, allocation, and risk metrics
  data.py              real adjusted-price acquisition and cache
  advanced_models.py   GARCH, hidden regimes, and rank-copula simulation
  backtesting.py       walk-forward evaluation, benchmarks, and costs
  validation.py        statistical and VaR-coverage tests
research_pipeline.py   complete real-data research orchestration
dashboard/             interactive deployable research product
tests/                 numerical, statistical, and integration tests
.github/workflows/     continuous validation and weekly data refresh
```

## Governance

This is educational research, not investment advice. Yahoo Finance data is a convenient research source rather than a licensed institutional feed. ETFs are imperfect asset-class proxies. Taxes, capacity, and nonlinear market impact are excluded. Historical and simulated performance cannot establish future profitability.
